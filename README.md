# Group Project Plan

## Program 1: 2048
A C++ implementation of the 2048 puzzle game on a 5×5 board with four-directional sliding/merging, score tracking, win/game-over detection, and save/load file validation.

## Program 2: Luhn Algorithm
A C++ program that implements the Luhn checksum algorithm for validating 16-digit numbers with input format verification, leading-zero preservation, and multi-check looping.
